# V1.0.1 — Task 02: Header, Topbar & Tool Rail Redesign

Scope: **header/topbar and tool rail only**. Tool panels, full control system,
export dialog internals, history UI, project dialogs, mobile-only behavior,
new features and version strings were left for later V1.0.1 tasks.

## 1. Structure & patterns changed

### Header / topbar (`resources/views/editor.blade.php`, `editor.css` §Top bar / §Buttons)

```
header.topbar (52px)
├── .brand
│   ├── svg.brand__mark — inline figure-8 (two circles, stroke = accent token)
│   └── span.brand__name — "8Pattern Editor" (unchanged text)
├── .topbar__file #file-meta — unchanged (#file-name / #file-dims)
└── .topbar__actions
    ├── .topbar__grp [aria-label="Undo history"]
    │   ├── button.btn.topbar__hist #btn-undo  (icon + label, disabled at rest)
    │   └── button.btn.topbar__hist #btn-redo
    ├── span.topbar__sep [aria-hidden]
    ├── .topbar__grp [aria-label="Project"]
    │   ├── button.btn.btn--ghost #btn-open
    │   ├── button.btn.btn--ghost #btn-reset
    │   └── button.btn.btn--ghost.panel-toggle #btn-panel
    ├── span.topbar__sep [aria-hidden]
    └── button.btn.btn--primary.topbar__export #btn-export  (new header action)
```

### Tool rail (`editor.blade.php`, `editor.css` §Shell)

```
nav.toolrail#toolrail [aria-label="Tools"] — 84px (70px ≤1100, 54px ≤640)
├── .tool[data-tool=adjust]  (is-active at boot, aria-pressed=true)
├── .tool[data-tool=film]
├── .tool[data-tool=effects]
├── .tool[data-tool=mask]
├── div.toolrail__sep [aria-hidden]        ← group break (no DOM reorder)
├── .tool[data-tool=crop]
├── .tool[data-tool=rotate]
├── .tool[data-tool=text]
├── div.toolrail__sep [aria-hidden]        ← workflow group break
└── .tool[data-tool=export]
```

Tool order in the DOM is untouched (`adjust, film, effects, mask, crop, rotate,
text, export`) — grouping is done with separators only, because tool order and
`mask between effects and crop` are hard test contracts (step11, step14,
final_checks).

### Why each change

- **Inline figure-8 brand mark** — the old `.brand__mark` was a CSS square; the
  header now carries the actual 8Pattern figure-8 identity, drawn with the
  accent token (`currentColor`), so no gold asset and no external URL.
- **Grouped actions + hairline separators** — history and project commands read
  as two clusters instead of one undifferentiated row (§15 grouping pattern).
- **Header Export (primary)** — the workflow-end action gets top-level
  hierarchy: `btn btn--primary topbar__export`. It does exactly what the rail
  Export tool does (`state.set({ activeTool: 'export' })`), so it presents
  existing functionality, no new feature. Hidden ≤640px where the rail tool is
  the entry point (tests filter buttons by `offsetParent`, so narrow viewports
  stay valid).
- **`.btn--ghost` made real** — open/reset/panel are now transparent at rest
  and raise a surface token on hover instead of competing with the primary.
- **Rail at 84px with 10px labels + 22px icons** — readable labels, ≥40px
  targets; group separators encode [edit] / [transform] / [workflow] without
  boxes or dividers heavier than `--line`.
- **Active tool state = bar + wash + accent + bold** — `inset 2px 0 0` accent
  bar, `--color-accent-subtle` wash, accent icon color, `font-weight: 700`
  label, plus `aria-pressed` on every tool (set in `EditorUI.sync`). Never
  color alone.
- **52px topbar** — a little more breathing room for 32px command targets.

## 3. Token usage

Accent family only: `--color-accent` / `--accent` (mark, focus, active tool,
primary Export), `--color-accent-hover`, `--color-accent-subtle` (active wash),
`--color-on-accent` (text on the yellow Export fill). Surfaces: `--bg-panel`,
`--bg-raised`, `--bg-hover`. Lines: `--line`. Text: `--text`, `--text-dim`.
Radii: `--radius-md` for the new controls. No hex literals outside tokens.

## 4. Accessibility

- `aria-pressed` on all 8 tools, kept in sync with `is-active`.
- `role="group"` + labels on the two header clusters; separators `aria-hidden`.
- Focus: existing `:focus-visible` accent rings (11 rules) cover the new
  button; Tab reaches the rail with a visible ring (verified live).
- Disabled state preserved on undo/redo with dynamic `aria-label`/`title`
  (`Undo <label> (Ctrl+Z)`).
- Active tool signals are redundant (bar + bold + wash + aria-pressed).
- `prefers-reduced-motion: reduce` disables header/rail transitions.
