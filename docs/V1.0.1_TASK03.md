# V1.0.1 — Task 03: Tool Panels & Editing Controls Redesign

Status: complete. UI-only change (§44): no editing-engine, serialization, history,
export or loading logic was modified. Version strings untouched (§39).

## What changed

### `resources/css/tokens.css`
- New token `--color-border-hover: #3a3a44` (+ legacy alias `--line-hover`) — the
  hover edge every control now uses, replacing the two `#3a3a44` literals that
  were left in `editor.css` from before the token system.

### `resources/css/editor.css` (the bulk of the task)
- **Panel header hierarchy** — first content section of every panel gets
  `.panel__section--lead`: 14px normal-case title + hint + divider. Remaining
  sections render as small uppercase labels with a hairline running to the edge
  (`.panel__title::after`). No panel title text changed (pinned contract).
- **Sliders** (shared by adjust/effects/grade/mask/export quality):
  4px track, 14px thumb on a panel-ring, thumb → accent on hover/active,
  disabled styling (faint thumb + reduced opacity), rows 8/16 padding,
  12px non-uppercase labels, 11.5px mono values (min-width 42),
  reset affordance visible at 0.45 opacity at rest (full opacity when
  dirty/hovered/focused) instead of hidden.
- **Group captions** — new `.adjust__group` class (deliberately not
  `.adjust__label`, so row counts/labels are untouched) marks
  **Light / Color / Detail** inside the Basic section.
- **Buttons** — one radius (`--radius-md`), hover via `--line-hover`;
  new `.btn--danger` (calm at rest, danger border on hover) on Delete Mask.
- **Selects / inputs** — export + mask selects 30px/radius-md/hover token,
  labels non-uppercase, checkboxes `accent-color: var(--accent)`,
  text hex/color/textarea/font-picker/search unified to the same radius family.
- **Presets** — 2-up grid (all nine names fit without ellipsis at 1440/1024),
  compact 30px buttons; applied state = accent wash + accent border + accent
  text + weight (never color alone).
- **Mask** — Brush/Erase read as a segmented pair; active mode is a filled
  accent button with on-accent text + `aria-pressed` (already set by JS).
- **Crop / text align** — segmented active state = accent-subtle wash +
  accent edge + weight (keeps existing `is-active` toggling).
- **History** — current entry uses the accent wash (was raised surface),
  keeping the inset bar + dot + `aria-current="step"`.
- **Scrolling** — thin scrollbar (Firefox + WebKit) on the panel and history list;
  history list bounded at 150px.
- **Semantics** — `.font-hint[data-state='failure']` is danger, not accent.
- **Disabled** — export Go button + all disabled buttons share one treatment.
- **Reduced motion** — existing block extended with panel control transitions.
- Legacy literals replaced: `#dcdce2` thumbs → `--color-text`, `#0b0b0d`
  crop-handle border → `--bg-app`, `--accent-soft` uses → `--color-accent-subtle`.

### `resources/js/editor/ui/EditorUI.js` (4 small edits, no engine touch)
1. `buildPanel` — marks the first content section `.panel__section--lead`.
2. `buildAdjustPanel` — appends the three `.adjust__group` captions.
3. Preset delegation — after `gradeCtl.applyPreset` (unchanged), marks the
   clicked look `is-active` + `aria-current="true"`; `buildControlRow` edits
   call `clearActivePresets()` so the state never lies after a tweak.
4. Delete Mask button gets `btn btn--danger` (text/id unchanged).

## Contracts deliberately preserved
- Panel titles `Basic|Color|Global|Cinematic` and `Film|Texture|Light|Presets`.
- 21 `.adjust` rows, label order, `is-dirty`, per-row markup.
- `formatValue` (`0`, `+60`), all hint/placeholder/button texts.
- `aria-current="step"` on history entries; preset uses `aria-current="true"`.
- cssText contracts (history/mask/recovery/custom-preset selectors).
- No preset was active before; the new active state is additive.
