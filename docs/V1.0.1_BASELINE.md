### Baseline discrepancies — investigated, not silently overwritten

**1) step9 hint race (148/149 on one run)** — the known V1.0 test race
(`pending load shows "Loading font…" hint`). Root-caused properly during
Task 01: `TextController.renderList`'s IntersectionObserver sometimes
ensures visible list faces (incl. Roboto 400:normal) during the earlier
`pickFont()` dropdown opens — before the section-X route exists — so at
check time the loader cache was warm, no loading hint ever appeared. The
old assertion also read the hint out-of-page after `waitForSelector`
(read-after-wait). Fix is test-side only, same assertion
(`state === 'loading' AND text === 'Loading font…'`): route both the
Roboto 400 and 700 files with the delay, start an in-page watcher before
any trigger, and force a fresh 700 ensure via the weight select — one
ensure is always fresh and hits the delayed route. Verified **6
consecutive runs 149/149** (4 before the final batch, plus the batch run
itself). Product code untouched.

**2) built CSS size swing (35–53 kB app.css)** — `resources/css/app.css`
scanned `storage/framework/views/*.php` (gitignored compiled-view cache)
via explicit `@source`, so built CSS depended on which views happened to
be compiled on the machine and could blow past step8's 60 kB lean-CSS
limit. Fix: dropped that one `@source` (compiled views are derived from
the blades already scanned). Deterministic now: app 35.12 + editor 18.18
+ tokens 1.60 = **53.62 kB < 60 kB**. Documented in app.css.

**3) tokens entry wiring** — `@import` inside editor.css is banned by
step9's privacy check, so tokens.css is its own Vite entry
(`vite.config.js` input + blade `@vite` array). A comment mentioning the
banned directive initially tripped the same check — comment reworded.

**4) blade edit encoding (found and fixed)** — an early one-line blade
edit via PowerShell mis-decoded the UTF-8 file (icons `↶`/`↷`, `§`, `—`
mojibaked, BOM added). Restored from git and re-applied the single
`@vite` line with a UTF-8-safe editor; verified 4 non-ASCII chars intact,
spot re-run (run_tests 98, step10 266, task01 35) green, then the full
final batch below run against the exact shipped state.

final Task 01 batch).
